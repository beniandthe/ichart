# Manual Free Ink selection experiment source archive

This is a source-only publication archive of the superseded manual-selection experiment, captured from original ref `codex/free-ink-selection-checkpoint` at commit `21a8541080a6a9d323586036c7fcd03ced848e7e`. Files retain their original repository-relative paths and exact source bytes. See `manifest.json` for provenance and checksums.

This archive is not a buildable repository, a current app candidate, or an acceptance receipt. Publishing it does not integrate, activate, install, test, or accept the experiment. Full original history and recovery references remain preserved separately and are not published by this snapshot. The current app's later automatic-articulation coordinator and interaction architecture supersede this manual path; replacing newer source with these files would undo later work.

The experiment expands a drag's full extent into a selection marquee, permits finger/Pencil/pointer selection, keeps a visible selection outline, allows an unrecognized selected mark to proceed to an explicit Choose Mark step, and reports a canvas-not-ready state. The Editor and Library files preserve the matching review/help wording. `ProjectConfigurationTests.swift` includes the two updated assertions for Select Ink/Choose Mark help. The checkpoint added no focused runtime regression methods; its source publication must not be described as fresh physical or regression acceptance.

All five changed Swift files are included as a historical snapshot: four app files and the relevant configuration/help test file. Dependencies and the remaining base application are intentionally absent. Do not use this archive to reopen marcato/new mark inputs or the separate reader-retry lane.

No device receipts, captures, QA binaries, real case identifiers, local recovery paths or credential files are included. Source files are unredacted exact copies; this README is newly authored technical context. The manifest's original commit and ref identify provenance, not a promise of a currently published or active branch. Graph/MyScript/ML-core research remains excluded.
