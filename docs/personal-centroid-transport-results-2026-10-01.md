# Fixed all-class personalization experiment: rejected

The one frozen centroid-transport recipe completed, but changed **no top-one
symbol decisions**. It did not improve either teaching task over the generic
encoder or unrelated-writer support. No final B8 fit, export or app activation
is justified by this result. No tuning or reserved-writer rescue was performed.

Base HEAD `160aa31594903508e241802e21ca83ec447de849`, branch
`codex/recognition-generalization-reset`, existing dirty worktree. Work was in
the recognition-generalization-reset checkout, not the environment's 717e
checkout. This is previously used public-character/internal-reuse evidence,
not fresh writers, natural chords, app accuracy or ship readiness.

## Executed preparation and fit

The source helper parsed coordinates only for the frozen A16 encoder-fit
writers. It regenerated all 3,104 raw embeddings with the exact fitA encoder,
including the 12 rows whose stored setup shape was unavailable. It did not
average the existing A16 crossfit embeddings, which came from fitB. Each of
97 centroids uses 16 raw embeddings/session, two sessions, float64 means and
normalization; all retained raw embeddings are float32 unit vectors.

The head runner materialized only 1,552 metaFit B8 rows as fit/prediction
tensors. Its parent loader also validated the existing pooled NPZ matrices;
that structural validation did not run an encoder or prepare excluded writers
as candidate tensors. The head's eight LOO folds each learned from seven
writers, with a disjoint eighth writer queried only after its head was frozen.
Both correct and unrelated lessons used the exact core10/catalog21 app-domain
labels, same support session and K. Training donors form a deterministic
derangement among the seven fitting writers; no held-out writer is a donor.

All plans were frozen before 8 x 30 x 28 = **6,720 actual updates**. All three
meaningful parameter blocks changed in each fold, with finite gradients,
finite losses and verified checkpoint reloads. The algebraically canceled
final bias remained exactly zero. Head fitting changed neither the encoder
nor input tensors. All 32 OOF episodes and full97 predictions were committed
before the separate scoring command opened held-out truth.

The runner's `encoderInferencePerformed:false` refers to that head/query stage.
The overall experiment **did** perform the permitted, separately receipted A16
centroid inference. Failed-validation B8, development, reserved and private ink
received no candidate inference; BHMSDS was not used.

## Independent reconciliation

The independent verifier imports no runner/model helper and performs no model
forward, fitting or centroid inference. It reconstructed the A16 means from
retained embeddings, bit-exact with maximum absolute error zero. It rebuilt
every source-only fold/copy ledger from pinned metadata and independently joined
the frozen predictions to labels. The entire score object, all group counts,
gains/harms, invalid semantics and rejection matched exactly.

It validated all 9,312 full97 probability vectors (903,264 values), eight
checkpoint byte/state bindings, 30 x 28 histories, cosine schedules, parameter
receipt values and final code/input/target hashes. Maximum probability-mass
error was at most 1.56e-15. It did not deserialize pooled/prepared feature
tensors or recompute generic predictions; it checked generic repeated-source
consistency. The scorer separately required exact equality to the prepared
generic-logit softmax.

This is not a bitwise inference no-op: candidate and unrelated probabilities
each differ from generic on all 3,104 scheduled rows. Candidate mean absolute
change per probability is 8.56e-8, maximum 6.15e-4; unrelated values are 9.00e-8
and 7.62e-4. Neither changes any top-one decision, including wrong-to-wrong
choices. Training and execution worked; this fixed mechanism produced no
demonstrated decision benefit. That does not establish that every possible
personalization architecture is ineffective.

Two earlier verifier reports are retained as verifier-schema failures, not
experiment failures: they omitted final verification/score fields. Only the
verifier was corrected. No frozen model, prediction, source, plan or scoring
recipe changed to obtain the final full reconciliation.
