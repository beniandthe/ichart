## Candidate and pure input contract

Inputs: frozen generic full97 logits, unit query features, unit centroid
matrix, explicitly labeled unit support features. No query targets, writer
IDs, session IDs, source indices or codepoint-specific parameters enter forward.
Deduplicate exact (label, feature) lesson copies and balance residual means
by label so repeated teaching does not manufacture a new style prior.

Let s be the label-balanced mean of (support feature - its class centroid).
Transport every class centroid as normalize(mu[c]+s); a degenerate zero norm
fails explicitly, not via a guessed direction. For each query/class, use four
features: generic logit, original cosine, transported cosine, cosine change.

all97 and add it to generic logits. Empty support bypasses the scorer and
returns bit-exact generic logits. No shortlist, alias, chord grammar rescue,
class embeddings or per-writer parameters. Validate finite full97 outputs.

predicts only the eighth after freezing. Correct support comes from the same

support writer with identical label set, support session and K. During a fold

the LOO writer. Select pairs/labels by source-only hashes and availability,
before logits or query truth. Abort if support coverage is insufficient.
Freeze copy reasons against every learned-stage source, not just encoder A16:

Fit head only, 30 epochs, AdamW lr .001 / weight decay .0001, cosine T_max30,
final checkpoint only; one source episode/update, 28/epoch and 840/fold.
No optimizer, width, loss-coefficient, support-set or checkpoint search.
Loss = equal taught/untaught full97 CE + preservation margin penalty +
KL(generic || unrelated-support candidate), all coefficients exactly 1.
The margin is truth logit minus maximum other-class logit. The penalty is mean
relu(generic truth margin - candidate truth margin) on rows where the generic
truth logit equals its full97 maximum (including tied maxima symmetrically);
zero if none. Balanced CE requires both nonempty strata; KL uses detached
generic softmax as target and mean full97 KL per query. Query truth/taught status
may enter this supervised objective and later scoring, never prediction.

Freeze all plans before optimization and all OOF full97 predictions before
scoring. For each K, require strict correct-support improvement over both
