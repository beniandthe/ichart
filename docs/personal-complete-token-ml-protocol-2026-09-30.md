# Complete-token ML alternatives — fixed development boundary

This intervention changes hypothesis assembly, not the shared encoder, personal learner, ownership resolver, live app reading, or acceptance thresholds. It is a comparison-only algorithm experiment, not a fifth ownership fit or a quality claim. No intended answer enters search; no label-specific or writer-specific substitution is introduced.

## Fixed algorithm

Input is a complete proposed source-index partition in a supplied reading order, with one to three retained single-NFC-codepoint ML ranks per column. Every original index must occur exactly once. Neither coverage nor supplied order verifies ownership. Only the separately selected lossless-source comparison route is eligible; legacy transformed groups and selective-unresolved proposals cannot enable this composer.

Sort each column by descending raw score, label, and original rank index. Enumerate complete Cartesian sequences with a best-first neighbor heap. Every neighbor increments one sorted rank position, so additive score cannot increase and the rank-position vector follows its predecessor even when floating-point scores tie. The tie policy is descending finite additive score, then lexicographic internal rank-position vector. Original rank indexes and raw tokens remain in candidate receipts.

Only full sequences reach `ChordSymbolParser`. Empty or missing columns, invalid partitions, nonfinite scores, oversized search limits and malformed ranks fail before search. Whitespace/control tokens count as rejected complete sequences rather than disappearing into parser cleanup. No shorter prefix, skipped mark, expected label, taught-whole-chord rescue, chord bonus, confidence cutoff or normalized survivor probability is used. Canonical aliases keep separate raw-token receipts.

Limits are fixed: 64 original strokes, 16 columns, three retained ranks per column, maximum 4,096 examined complete sequences and 16 retained candidates; the UI uses three candidates. The retained-rank universe size is explicit. `searchComplete` means every sequence in that universe was examined. `omittedCandidates` means valid examined hypotheses exceeded the result cap. `truncated` reflects either limitation. Unexamined validity and omitted model-vocabulary ranks remain unknown.

## App and evidence boundary

One existing Debug comparison menu offers the historical paired comparison or the new complete-symbol alternative comparison. The new route fits only the pre-test frozen profile, preserves exact lossless inputs, saves a new report, and honors current opt-out/profile changes before publication. Shared, original personal, and available anchored alternatives remain separate.

Historical top-1 predictions and scorecards remain unchanged. Alternative presence is not scored as an exact read or a gain. A report-level method version preserves the requested route even when every row is unsupported and contains no hypotheses. The UI explicitly labels alternatives unscored and conditional on unverified grouping and reading order. There is no render/accept/teach action or live fallback in this route. Earlier reports decode with absent optional fields, not invented alternatives.

Synthetic gates compare heap output against exhaustive Cartesian enumeration, test invalid/partial ownership and unread-suffix preservation, retain valid-but-wrong first choices, verify labels do not affect search, test bounded/tied/negative scores, and check app saving/opt-out compatibility. These gates establish implementation behavior only.

Before recognition-quality claims, freeze this algorithm and evaluate independent fresh natural chord writing in both chart styles with separately reviewed ownership and raw-symbol truth. Report candidate coverage separately from selected exact reads, gains, harms, no-reads and false ownership. Do not select a favorable candidate after seeing the intended answer or treat the candidate list as a calibrated prediction. Existing public development writers and previously corrected user ink are diagnostics, not a new-writer gate.
