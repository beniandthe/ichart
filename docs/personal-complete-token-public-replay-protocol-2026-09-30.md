This is a component diagnostic on already-observed public development writers, not fresh natural chords, independent new writers, personalized quality, or shipping evidence. No new model inference, training, private chart/profile access, or reserved-writer use is permitted in this pass.

Use every one of the 3,104 rows in the existing `public-conditional-identity-v1` report: 1,552 isolated-character queries and 1,552 mechanically adjacent-character queries. Input report SHA-256 is `c4b6acc6caf76e0f7d0af9ee8036cd672673f1690e790fee3dcf14fea329c01b`. Retain row IDs, arm, exact original-index groups, original top-1 tokens, legacy greedy complete-parser output, and the composer's entire result or explicit failure. Use only generic ranks. Failures stay in the row set. Write an append-only prediction file and bind its source report SHA, runtime identity, and executed code hashes before starting a separate scoring process.

Composer is `conditional-complete-token-lattice-v1`, source SHA `d2988c65de55ee43e8462cbee5063c532f27c43a479c2c1f9307acb92562d288`. Defaults are fixed: maximum 4,096 examined sequences and three retained candidates. The first retained candidate is the fixed selected hypothesis for this diagnostic. ## Separate scoring

Join the frozen predictions to the unchanged source report by unique row ID; require exact row-set, arm, group, and source binding agreement. Only then parse source expected tokens with the same existing `ChordSymbolParser`. This determines a diagnostic grammar-valid subset; arbitrary public characters/pairs do not become natural chord writing.

For each construction arm and each ownership route, keep all rows as the denominator. Report raw exact top-1 tokens separately from grammar-normalized comparison. For grammar-valid source strings, report fixed first-candidate correct/wrong/no-hypothesis, original greedy correct, paired gains/harms/both/neither, and any-retained-candidate coverage separately. Coverage is not a correct selected read. For grammar-invalid source strings, report grammar-valid hypotheses produced; this is a diagnostic warning, not a measured false-acceptance rate because no hypothesis is accepted or rendered.

Keep exact source-owner partition and supplied reading-order matches separate from canonical text matches. A text match under wrong automatic ownership is not ownership evidence. Retain failures, incomplete-search counts, omitted-candidate counts, per-writer denominators, and every row for reconciliation. The two routes are paired observations, not independent samples. Writers and repeated constructions are correlated; do not manufacture statistical independence or pool them into a product accuracy percentage.

These observations can decide whether grammar assembly merits further investigation. They cannot justify promoting this comparison-only composer into live recognition. Fresh natural chords in both chart styles, independent reviewed ownership/symbol truth, personalization gains and harms, and a new-writer gate remain required.
