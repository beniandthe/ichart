# Historical handwritten-repeat feedback QA — retired

These receipts and images describe the October 27 implementation. Handwritten
repeat ingestion was retired by user decision on November 5, 2026. These files
are preserved historical evidence, not current product instructions or proof
that a supported handwriting-to-repeat feature exists.

Use **Tools > Repeats** and selected measures for current structured repeat
entry. Existing saved repeat notation and source ink remain preserved. See the
