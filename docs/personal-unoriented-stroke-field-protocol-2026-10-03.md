# Direction neutral stroke field experiment

Freeze this protocol and executable code before preparing real features or
fitting. Run one matched experiment, not a parameter search. The previous
[direction diagnostic](personal-stroke-direction-diagnostic-results-2026-10-03.md)
established sensitivity in a rejected model, not the cause of natural writing
errors. This candidate tests whether geometry without motion polarity provides
a better general encoder for the existing customizable ML pipeline. It does
not change the app or establish a personalization benefit.

seed 29, optimizer, balanced cycling schedule, final-only 30 epochs, CPU four

SHA256 3cda2bcb7c64a79c3ef4371a8ef01fb1df0e0e75512a7f2f49f39cdc58ff9d13.
Do not change or impersonate the old protocol, versions, or receipts. Reuse
its frozen stateless source, scheduling, optimizer-step, and scoring helpers
through explicit new versioned wrappers. No monkeypatching or source rewriting.

The only representation change is five registered Float32 planes:
app-exact occupancy, length-weighted local orientation xx, xy, yy, and the
union of stroke endpoints. Average each segment's unit-direction outer product
before aggregation, not the outer product of a signed mean direction. Canonical
segment endpoint ordering makes reversal arithmetic deterministic. Opposite
retracing must retain orientation rather than cancel. There is no timing,
start/end distinction, stroke acquisition order, label, or writer feature.

Both arms use the same existing five-input convolutional architecture and
identical complete initial state. The control masks the four auxiliary planes
inside forward. Train both arms afresh. Keep the prior spatial affine draws;
rotate the orientation tensor with the physical forward rotation R(-angle)
as R Q R-transpose, and transform occupancy/endpoints as scalar planes. No
reflections, test-time augmentation, reversal selection, ensembles, new
thresholds, or class-specific rules.
